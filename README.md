# haven-web

Páginas públicas de Haven servidas con GitHub Pages:

- `privacy-policy.html` — Política de privacidad
- `terms.html` — Términos de servicio
- `eliminar-cuenta.html` — Cómo eliminar la cuenta (exigido por Google Play)
- `auth-callback.html` — Destino de los enlaces de los correos de Supabase
  (confirmar cuenta / recuperar contraseña)

El código de la app vive en un repositorio privado aparte; este repo es
público solo para que GitHub Pages pueda servir estas páginas.
